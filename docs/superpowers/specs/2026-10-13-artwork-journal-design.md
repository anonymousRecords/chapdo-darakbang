# 날짜별 작품 일지

## 목적과 승인된 흐름
Next.js에서 매일 작품 하나와 제작 이유를 함께 게시한다. 사용자가 승인한 MDX 방식으로 구현한다. 메인은 날짜와 제목의 최신순 목록이며, 상세는 작품 실행 영역과 저자의 글, 이전·다음 게시물로 구성한다. antfu/100의 간결한 텍스트 목록을 참고한다.

## 구조
기존 apps/gallery Next.js App Router와 정적 export를 확장한다. 기존 Vite 작품과 /interactions/{id}/ URL을 유지하고 상세 페이지에서 iframe으로 실행한다. 글은 apps/gallery/content/works/*.mdx에 저장하고 파일명이 상세 URL /works/{slug}/가 된다. title, date, interaction은 필수이고 draft, desktopOnly는 선택이다. 글 내용은 저자가 저장소에서 작성한 MDX만 서버에서 컴파일한다.

## 게시 규칙
date는 YYYY-MM-DD이다. 기존 README 이관에 한해 YYYY-MM을 허용해 날짜를 지어내지 않는다. 날짜는 달력상 유효해야 하며, 작품 ID는 레지스트리에 있어야 한다. 빈 제목·본문, 잘못된 날짜·boolean·작품 ID는 파일명과 함께 빌드를 실패시킨다. draft: true 및 한국 날짜 기준 미래 글은 목록·상세 정적 경로에서 제외한다. 정적 사이트이므로 미래 글 게시에는 해당 날짜 이후 재빌드·배포가 필요하다. 같은 날짜 글은 파일명으로 안정적으로 정렬하며 하루 한 작품은 저자의 작성 관례로 둔다.

## 이관과 화면
README의 신호등, 열리는 상자, 방송실의 음향 슬라이더, 기묘한 이야기 네 글을 원문과 관련 링크 그대로 옮긴다. 글이 없는 작품은 메인의 별도 기존 실험 목록에서 실행할 수 있다. 메인과 글은 모바일에서도 읽을 수 있으며 desktopOnly 작품은 작은 화면에서 실행 안내를 보여준다. 날짜는 time 요소, 작품 목록은 실제 링크, 상세는 제목·설명 메타데이터와 404 처리를 갖춘다.

## 시각 방향
밝은 종이색 #f8faf9, 잉크 #23352d, 보조 글자 #66736c, 경계 #dde5df, 녹색 #286344. 기존 로컬 Geist와 한국어 시스템 글꼴을 사용한다. 폭 760px의 왼쪽 정렬 일지, 날짜 열과 제목 열, 월별 묶음으로 기록을 읽기 쉽게 한다. 프리뷰 카드와 장식적인 모션 대신 작품 자체에 시선을 둔다.

## 검증
실제 임시 MDX 파일 기반으로 정렬, KST 경계, 초안·미래 제외, 월 정밀도, 유효성 오류를 검증한다. Next.js 타입 검사·갤러리 lint·전체 배포 빌드와 로컬 브라우저에서 목록→상세→작품 실행, 작은 화면 글 읽기를 확인한다.
